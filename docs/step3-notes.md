# ঘরের খবর — ধাপ ৩ (সিঙ্ক ও সেটআপ)

## এই ধাপে যা হলো
- **প্রথমবার খুললে সেটআপ স্ক্রিন** আসবে: নোটিফিকেশন অ্যাক্সেস, ব্যাটারি অপ্টিমাইজেশন থেকে বাদ দেওয়া, ব্যবহারকারীর নাম, সম্পর্ক (ছেলে/মেয়ে/আম্মু/অন্যান্য), এবং Apps Script Web App URL ও API Key। এই দুটো আপনি ধাপ ১-এর Deploy থেকে পাওয়া URL আর API_KEY (ADMIN_KEY নয়) বসাবেন।
- সংরক্ষণ করলে ডিভাইসটা ব্যাকএন্ডে রেজিস্টার হয় এবং সাথে সাথে একবার সিঙ্ক হয়।
- **ব্যাটারি অপ্টিমাইজেশন গাইড**: এটা বাদ না দিলে অনেক ফোনে (বিশেষ করে Xiaomi, Oppo, Vivo, Samsung) ব্যাকগ্রাউন্ড সিঙ্ক বন্ধ হয়ে যায়। বাটনে চাপলে সরাসরি সিস্টেম পারমিশন ডায়ালগ আসবে।
- **সিঙ্ক নিয়ম**: প্রতিদিন একবার ব্যাকগ্রাউন্ডে চেক হয় — নতুন অপাঠানো মেসেজ থাকলে তখনই নেটওয়ার্কে পাঠায়, না থাকলে কিছুই পাঠায় না (তাই ডাটা থাকলে কার্যত ডেইলি, না থাকলে কার্যত সাপ্তাহিক বা তার চেয়েও কম — কোনো অপ্রয়োজনীয় নেটওয়ার্ক কল হয় না)। ইন্টারনেট না থাকলে বা পাঠাতে ব্যর্থ হলে পরে আবার চেষ্টা করে।
- **সিঙ্ক স্ট্যাটাস স্ক্রিনে** দেখা যাবে: সংরক্ষিত মেসেজ সংখ্যা, এখনো না পাঠানো সংখ্যা, শেষ সিঙ্কের সময় ও ফলাফল। "এখনই সিঙ্ক করুন" বাটন দিয়ে টেস্টের সময় সাথে সাথে পাঠানো যাবে।
- ইমার্জেন্সি বন্ধ চালু থাকলে সিঙ্কও বন্ধ থাকবে (নতুন মেসেজ ধরাও বন্ধ, আগে থেকে থাকলে তাও পাঠানো হবে না)।
- প্রতিটি মেসেজ একবারই সফলভাবে পাঠানো নিশ্চিত হয় (`synced` কলাম), তাই বারবার পাঠানোর সমস্যা হবে না।

## ব্যাকএন্ড কাজ
নতুন কোনো Apps Script কোড পরিবর্তন লাগবে না (ধাপ ১-এর ব্যাকএন্ড এটা সামলাতে পারে)। শুধু মনে রাখবেন: সেটআপ স্ক্রিনে API Key বসাতে হবে — Apps Script-এর `showKeys` ফাংশন Run করলে Execution log-এ `API_KEY` দেখা যাবে, সেটাই বসাবেন (ADMIN_KEY অ্যাডমিন অ্যাপের জন্য, পরের ধাপে লাগবে)।

## টেস্ট করবেন যেভাবে
1. অ্যাপ খুলুন, সেটআপ স্ক্রিনে সব তথ্য দিন, "সংরক্ষণ করুন ও রেজিস্টার করুন" চাপুন।
2. Google Sheet-এর **Devices** ট্যাবে এই ফোনটা একটা সারি হিসেবে দেখা যাবে কিনা দেখুন।
3. নিজেকে WhatsApp/imo-তে মেসেজ পাঠান, অ্যাপে ফিরে "এখনই সিঙ্ক করুন" চাপুন।
4. Google Sheet-এর **Messages** ট্যাবে মেসেজটা দেখা যাচ্ছে কিনা দেখুন।
5. স্ট্যাটাস স্ক্রিনে "শেষ সিঙ্ক" ও ফলাফল আপডেট হয়েছে কিনা দেখুন।
