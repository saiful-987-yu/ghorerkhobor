# ঘরের খবর — ধাপ ৪ (অ্যাডমিন অ্যাপ)

## এই ধাপে যা হলো
নতুন প্রজেক্ট: `admin-app` (প্যাকেজ `com.ghorerkhobor.admin`)।

- **পিন লক**: প্রথমবার খুললে ৪-৬ সংখ্যার পিন সেট করতে হবে (হ্যাশ করে সংরক্ষিত হয়, প্লেইন টেক্সটে থাকে না)। পরবর্তী প্রতিবার অ্যাপ খুললে পিন চাইবে।
- **সার্ভার সেটিংস**: Apps Script Web App URL ও **Admin Key** (`showKeys` Run করলে যেটা পাওয়া যায়, API_KEY নয়) — একবার দিলেই থাকবে, settings আইকন দিয়ে পরে বদলানো যাবে।
- **ডাটা আনা**: Devices ও Messages দুটোই ব্যাকএন্ড থেকে fetch হয়।
- **ফিল্টার**: ব্যক্তি (ডিভাইস রেজিস্ট্রেশন থেকে), অ্যাপ (WhatsApp/imo/Messenger/Telegram/Viber), এবং একটা নির্দিষ্ট তারিখ — একসাথেও ব্যবহার করা যায়।
- **সার্চ**: নাম, টাইটেল, টেক্সট ও কথোপকথনের মধ্যে খোঁজে।
- **ডার্ক/লাইট মোড**: উপরের আইকনে চাপলে বদলে যায়, পছন্দ সংরক্ষিত থাকে।
- তালিকায় ট্যাপ করলে বিস্তারিত স্ক্রিনে পুরো মেসেজ ও (থাকলে) ছবি দেখা যায়।

## একটা কারিগরি সীমাবদ্ধতা, যা জানা দরকার
ব্যাকএন্ডে সরাসরি "নির্দিষ্ট তারিখ থেকে" ফিল্টার করার ব্যবস্থা নেই (কোনো ব্যাকএন্ড কোড বদলাইনি), তাই তারিখ বা সার্চ ব্যবহার করলে অ্যাপ নিজে পেছনের দিকে পাতার পর পাতা (সর্বোচ্চ ১০ পাতা, ২০০০ মেসেজ) খুঁজে ফলাফল বের করে। কোনো ব্যক্তি/অ্যাপের মেসেজ এর চেয়েও পুরনো হলে "আরও লোড করুন" চেপে আরও পেছনে খোঁজা যাবে।

## ব্যাকএন্ড কাজ
কোনো ব্যাকএন্ড কাজ নেই। ধাপ ১-এর ব্যাকএন্ডই যথেষ্ট।

## টেস্ট করবেন যেভাবে
1. `admin-app` ফোল্ডারটা Android Studio-তে খুলুন, নিজের ফোনে Run করুন।
2. পিন সেট করুন।
3. সার্ভার URL ও Admin Key দিন।
4. ইউজার অ্যাপ থেকে সিঙ্ক হওয়া মেসেজ এখানে তালিকায় দেখা যাচ্ছে কিনা দেখুন।
5. ব্যক্তি/অ্যাপ/তারিখ ফিল্টার করে এবং সার্চ করে দেখুন ঠিকমতো ফলাফল আসছে কিনা।
6. একটা মেসেজে ছবি থাকলে সেটাতে ট্যাপ করে ছবি লোড হচ্ছে কিনা দেখুন।
